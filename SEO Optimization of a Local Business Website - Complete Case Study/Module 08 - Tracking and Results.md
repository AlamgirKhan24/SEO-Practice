# Module 8: Tracking and Results

## Project context

- **Practice business:** GlowCare Salon (fictional)
- **Website status:** No live site or tracking properties yet.
- **Purpose:** After the website and measurement tools are live, track results for 2–3 months and compare them with the Module 2 baseline. Do not fill in sample numbers as if they were measured results.

## What to do

Use the same tools, definitions, date ranges, and settings when comparing baseline and later results. SEO results can take time and vary by season, competition, and how much data a site has; do not promise a particular amount of growth or a fixed timeline.

## Checklist

- [ ] Once the site is live, set a weekly quick review and a monthly full review. Add reminders to your own calendar if useful.
- [ ] In GA4, record total users, organic search users, top landing pages, and configured conversions for each full month.
- [ ] In Search Console, record clicks, impressions, CTR, and average position for consistent date ranges. Note country, device, and search type filters.
- [ ] Update the 10–15 target search phrases every two weeks using the same location and method. Treat manual rank checks as directional because results vary by location and personalization.
- [ ] Re-test the same URLs in PageSpeed Insights. Record device type, date, performance score, and Core Web Vitals. Label field data and lab data separately.
- [ ] Check backlinks and referring domains with the same provider where possible. Third-party tools have different coverage; their counts are estimates.
- [ ] If the business is real and has an eligible, verified Google Business Profile, record available profile interactions and review counts. Do not create a profile for the fictional example.
- [ ] Review indexing reports and important URLs in Search Console.
- [ ] Track useful conversions such as form submissions, phone clicks, or direction clicks only after events are implemented and checked.
- [ ] Keep a dated change log for on-page edits, technical fixes, content publications, and legitimate local/off-page work.
- [ ] Make simple charts in Google Sheets or a Looker Studio dashboard after enough observations exist.

## Percentage change guidance

Use `(new value - baseline value) / baseline value × 100` only when the baseline is greater than zero and both values measure the same thing over comparable periods. If baseline is zero, report the absolute change (for example, “0 to 3 clicks”) instead of a percentage. For average position, lower numbers indicate a better average position; explain the direction when reporting change. Do not combine counts from different backlink providers as though they share the same database.
