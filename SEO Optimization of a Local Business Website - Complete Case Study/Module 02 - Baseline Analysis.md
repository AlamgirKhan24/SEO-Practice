# Module 2: Baseline Analysis

## Project context

- **Business:** GlowCare Salon (fictional practice business)
- **Location:** University Town, Peshawar, Pakistan
- **Website:** Not created or selected yet
- **Baseline status:** Live measurements are not available. Do not invent values; enter them after a demo website is live and connected to tracking.

## Purpose

Record website performance before making SEO changes. Use the same tools, date ranges, and measurement setup for the final comparison.

## Checklist

- [ ] Build or choose the demo website and record its URL.
- [ ] Connect Google Search Console and GA4; record the connection date.
- [ ] In GA4, record total users, organic search users, and top 5 pages for the last 28 days.
- [ ] In Search Console, record clicks, impressions, CTR, and average position for the last 3 months.
- [ ] Choose 10–15 local salon searches and record current rankings. If the website is new, use “not ranking.”
- [ ] Test the homepage and two other pages with PageSpeed Insights. Record mobile and desktop scores and LCP, INP, and CLS.
- [ ] Check backlinks and referring domains with a free tool, if available.
- [ ] Check indexing with `site:yourwebsite.com` and review Search Console’s Pages report.
- [ ] Save dated screenshots or exports of the reports.
- [ ] Record a quick comparison for three real local competitors.

## Free tools

- Google Search Console
- Google Analytics 4
- PageSpeed Insights
- Google Search
- Google Sheets
- Ubersuggest (limited free use) or Ahrefs Webmaster Tools (where eligible)
