## What to do

Improve each page so its title, headings, copy, images, links, and contact action clearly help both visitors and search engines understand that page. Drafts below are starting points. Replace placeholders with accurate details and do not claim services, prices, credentials, or opening hours unless the business confirms them.

## Page content outline

- **Home:** Briefly explain what the salon offers and where it is. Link to each service page, show confirmed differentiators, and provide a visible booking/contact action.
- **Hair services:** Explain the haircut and other hair services actually offered, who they suit, how to book, and any confirmed price guidance. Link to coloring and contact pages.
- **Hair coloring:** Describe available coloring options, consultation needs, care advice, and confirmed price information. Add original salon images with descriptive alt text where appropriate.
- **Bridal makeup:** Explain the actual package options, booking lead time, trial availability, inclusions, and portfolio. Do not invent package details.
- **Party makeup:** Describe occasions served, what the appointment includes, preparation guidance, and how to check availability.
- **Skincare:** List only confirmed treatments, explain what a visitor can expect, and provide appropriate contact guidance. Avoid unsupported health or treatment claims.
- **Services and prices:** Show current confirmed services and prices or state how to request a quote. Add a last-updated date if prices change often.
- **About:** Use genuine background, staff information, and salon photos once available.
- **Contact:** Add verified address, phone, opening hours, map/directions, and booking options.
- **Blog guide:** Answer bridal service planning questions with practical advice and link to the bridal makeup and contact pages.

## On-page checklist

- [ ] Give every page a distinct, descriptive title and meta description.
- [ ] Use one clear page-level H1 as a practical structure; organize sections with descriptive H2/H3 headings.
- [ ] Keep each URL short, readable, and stable. Redirect an old URL if an existing live URL must change.
- [ ] Write useful, original copy that answers the visitor's question. Do not write to a word-count quota; cover the topic fully without padding.
- [ ] Mention the primary topic naturally near the start where it reads well; avoid repetitive keyword stuffing.
- [ ] Use descriptive image filenames and useful alt text for informative images. Use empty alt text for decorative images. Compress images with Squoosh or TinyPNG.
- [ ] Link related pages with clear anchor text and make key pages easy to reach from navigation and the homepage.
- [ ] Add a visible contact or booking action on key pages. Use real confirmed details; replace `[PHONE]` and similar placeholders before launch.
- [ ] Check mobile layout, spelling, page links, and contact actions.
- [ ] After launch, use Search Console URL Inspection to request indexing for important updated URLs; a request does not guarantee indexing.
- [ ] Record actual update and indexing-request dates.
