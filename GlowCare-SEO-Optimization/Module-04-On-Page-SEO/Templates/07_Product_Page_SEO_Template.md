# Product Page SEO Template

**Status:** Reusable template. Populate only from verified product/manufacturer documentation and current catalog data.

- **Product name / H1:** `{Brand} {Exact Product Name} — {Variant or Size}`
- **SEO title:** `{Exact Product Name} {Size} | GlowCare Pakistan` (only if sold and title is unique)
- **Meta description:** `Explore {Exact Product Name} at GlowCare. Review verified ingredients, directions, size and availability before ordering.`
- **URL:** `/products/{brand-product-name-size}/` — stable lowercase slug; omit unnecessary claims or temporary price.
- **Product description:** Short, factual summary of product type, stated purpose and notable attributes, based on an approved source. Do not convert marketing language into medical claims.
- **Specifications:** Brand, exact name, variant, size, form, country of origin if verified, barcode/SKU if useful, stock and price from current system.
- **Ingredients:** Publish the exact label/INCI list only after source verification and version control. Mark missing data for follow-up; do not infer formula.
- **Directions and cautions:** Transcribe/faithfully summarize manufacturer instructions, warnings and suitability statements. Do not improvise advice.
- **Images:** Front, back/label, texture/scale if genuine and representative; descriptive filenames; useful alt text; compressed WebP/AVIF with responsive delivery.
- **Related products:** Relevant categories and genuinely related stocked items; avoid unsupported “works best with” claims.
- **Breadcrumbs:** Home > Skincare > Category > Product.
- **Internal links:** Parent category, brand page if valid, shipping/returns, related factual guide.
- **Structured data:** Use `Product` with accurate name, image, brand, SKU/GTIN, description and offers only when verified. Keep price/availability synchronized. Use genuine review data only if collected and displayed compliantly; markup never guarantees rich results.
- **Reviews:** Collect authentic post-purchase feedback transparently; disclose incentives; do not fabricate or selectively misrepresent.

**Required verification fields:** Ingredients, size, directions, warnings, price, inventory, origin, brand authorization/sourcing language, images, review source.
