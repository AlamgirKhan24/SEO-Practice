# Content Optimization Report

**Status:** Proposed recommendations; GlowCare has no live site or catalog for a current-state audit.

## Approach
Use Module 03’s provisional keyword-to-page map as intent guidance, not search-demand proof. Category pages should help shoppers compare the actual available range. Product pages should answer product-specific questions using manufacturer/supplier documentation. Guides should address verified information needs without diagnosis or efficacy promises.

## Recommendations by template
- **Homepage:** State the actual offer and country served once confirmed; provide clear category routes, customer support, delivery/returns links, and selected guide links. Avoid broad claims like “best” or “100% authentic” without evidence.
- **Category:** A concise introduction should explain what is listed and how a shopper can compare documented attributes. Include useful filters based on actual catalog data; avoid large generic text blocks. Link to relevant guides and subcategories.
- **Product:** Provide exact product name, variant/size, manufacturer supplied ingredients, directions, cautions, availability, price, delivery details and image views. Separate verified facts from seller copy and cite/source internally.
- **Informational pages:** Use plain language, descriptive headings, authoritative citations, named qualified reviewers only when real, publication/review dates, and a clear scope. Link to products only when directly relevant.

## Quality checks
Use natural terms in title, H1, introductory copy, and internal anchors. Satisfy the likely intent before adding supporting details. Keep language readable and localized; have Urdu translations reviewed by fluent editors. Check uniqueness across pages, broken links, mobile readability and accessibility. Never add copy just to hit a word count.
