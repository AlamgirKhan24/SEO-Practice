# Organic Traffic Analysis Framework

1. Start with comparable periods and annotate launches, outages, campaigns, stock changes and seasonal dates.
2. In GSC, examine clicks/impressions/CTR/position by query, page, country and device; use query-to-page joins to find page overlap. The displayed query set may omit some queries.
3. In GA4, use Organic Search acquisition and landing pages; segment country/device and new/returning only where data thresholds and consent permit.
4. Interpret sessions with engagement and downstream events. A high bounce/low engagement signal alone does not prove a problem; assess task completion and content intent.
5. Find traffic growth/decline via comparable trend lines and stable canonical page groupings; check whether changes come from query mix, seasonality, technical issues, content, or tracking.
6. Identify high performers by qualified clicks and engaged/commercial actions, not traffic volume alone. Diagnose low-performing pages with low impressions (discovery/relevance), impressions but low CTR (snippet/position mix), or clicks but weak engagement (intent/page experience).
7. Assess conversion paths with GA4 path/funnel explorations after event QA; reconcile to backend orders. Attribution is model-dependent; assisted conversions are not incremental proof.
8. Separate measured facts from hypotheses and record a next action, owner and verification date.
