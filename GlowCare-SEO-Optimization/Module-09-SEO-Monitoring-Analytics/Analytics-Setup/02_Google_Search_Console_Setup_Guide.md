# Google Search Console Setup Guide

**Instructions only. No GlowCare property was created or verified.**

1. Confirm canonical domain and account owner. Grant least-privilege delegated access to the SEO analyst.
2. Add a Domain property (`glowcare.example`) where DNS control exists; it covers protocol/subdomain variants and uses DNS verification. A URL-prefix property is an alternative for a specific protocol/host/path and supports other verification methods. Follow the account-specific instructions. [Verify ownership](https://support.google.com/webmasters/answer/9008080)
3. Keep DNS verification records in place and protect account access with strong authentication.
4. Submit the production sitemap index (or sitemap) in the Sitemaps report only after the live site returns the correct canonical URLs. Submission does not guarantee indexing.
5. Inspect homepage, priority category, product and guide URLs with URL Inspection: check indexed status, crawl/robots/canonical/last crawl and request indexing only when appropriate.
6. Review Page indexing and sitemap reports weekly after launch, then monthly; investigate excluded URLs against intended indexation.
7. Performance report: select Web; set date range; compare equivalent periods; segment by queries, pages, countries (Pakistan), devices, search appearance. CTR = clicks/impressions. Average position is a summary metric, not a fixed rank.
8. Analyze query/page combinations to detect cannibalization and intent mismatch. Consider seasonality, changes in query mix and data freshness before conclusions.
9. Monitor Core Web Vitals when field data exists, Manual actions and Security issues. An empty report is not proof of an audit if the property is unverified.
10. Export dated data to a controlled workspace; redact sensitive information before sharing.

Ownership verification is required to access property data. [Getting started](https://support.google.com/webmasters/answer/10267942) · [Performance metrics](https://support.google.com/webmasters/answer/7042828)
