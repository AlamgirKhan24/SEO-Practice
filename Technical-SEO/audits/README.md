# Audit archive

Each site review is stored in a dated folder named `{site-name}-{YYYY-MM-DD}/`. Audit folders keep the evidence, prioritized work, report, and fix history together.

| Island Route | 2026-09-04 | Findings, issue tracker, change log, HTML report |

Each dated folder contains the materials available for that audit. Reports should be read alongside their findings and issue tracker for context on scope and prioritization.

## Standard audit files

- `findings.md` — documented observations and supporting details
- `issue-tracker.md` — prioritized recommendations and status
- `report.html` — designed summary for review and sharing, when included
- `CHANGELOG.md` — changes applied and verification notes for that audit
