# Checklist: Site Architecture

Review whether the URL structure and internal links make important content easy to discover and understand.

- [ ] URL patterns are consistent, readable, and stable where practical
- [ ] Important page types have a clear place in the site hierarchy
- [ ] High-value pages are reachable through useful internal links, not only through a sitemap
- [ ] Internal links use descriptive labels and point to preferred URLs
- [ ] Broken internal links and redirecting internal links are identified
- [ ] Breadcrumbs, when useful, reflect the visible navigation hierarchy
- [ ] Related pages link to each other in ways that help users and crawlers discover content
- [ ] Pagination and faceted navigation provide a crawlable, intentional path
- [ ] Orphaned pages are reviewed for importance before removal or linking recommendations
- [ ] Navigation and URL structure remain understandable on mobile
- [ ] XML sitemaps are consistent with the intended URL architecture

Avoid treating a fixed click-depth target or URL style preference as a defect without evidence that discovery, usability, or maintenance is affected.
