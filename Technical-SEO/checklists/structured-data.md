# Checklist: Structured Data

Review structured data only where it accurately describes visible page content and supports the page's purpose. Markup does not guarantee a rich result.

- [ ] Select types that fit the page and are supported by current search or schema documentation
- [ ] Confirm properties describe visible, current, and accurate page content
- [ ] Check for duplicate, conflicting, or contradictory entities across plugins and templates
- [ ] Validate syntax with a suitable validator; use Google's Rich Results Test only for supported rich result types
- [ ] Review warnings and required properties against current documentation
- [ ] Confirm URLs, images, organization details, and identifiers are valid and consistent
- [ ] Check that breadcrumbs match the user-visible hierarchy where present
- [ ] Test representative page templates, including mobile-rendered pages
- [ ] Revalidate after template or SEO plugin changes
