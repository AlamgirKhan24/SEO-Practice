## Tool governance

Save dated exports and record property, filters, date ranges, country, and definitions. Never blend tool estimates with measured first-party metrics without a clear label. Use least-privilege delegated access; do not place passwords, API secrets, payment/customer information, or unredacted personal data in deliverables. If paid access is unavailable, proceed with public SERP observations, free tools, and source exports while explicitly noting coverage limits.
