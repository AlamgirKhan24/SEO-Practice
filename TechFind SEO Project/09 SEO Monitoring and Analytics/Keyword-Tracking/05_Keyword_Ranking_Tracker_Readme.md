# Keyword Ranking Tracker Instructions

The companion workbook is preloaded with 15 priority candidates from Module 03. Target URLs remain pending actual domain/page confirmation. Current/previous rankings and movement are blank/unmeasured; no sample positions are fabricated.

## How to use

- Track a fixed query set by country, device, search engine, date and consistent location settings in a rank-tracking tool if precise rank is needed.
- GSC's average position is useful directional Search performance data but varies by impressions/query mix and is not an exact rank for a specific person/location.
- Save raw dated exports and record tool, geography, device, language, URL, and tracking settings.
- Investigate drops by query and landing page; verify impressions/clicks, indexed URL, canonical, stock state, SERP changes, device and release annotations.
- Detect cannibalization by finding multiple TechFind URLs receiving impressions for the same query cluster. Review intent overlap, internal links, canonicals and page purpose before consolidating.
- Prioritize relevant commercial intent and meaningful impressions/conversions, then assess content fit and ability to serve the query. Volume/KD from Module 03 is unavailable.

## Columns

Keyword, intent, target URL, target location, device, current/previous rank, movement, tracking date, source and notes. Movement formula when ranks are filled: previous position minus current position (positive = improved). Leave blank when either position is missing.
