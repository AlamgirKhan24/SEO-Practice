# Initial SEO Strategy (Planning Only)

This is a high-level plan. No audit, keyword research, implementation, outreach, or tracking configuration has been performed.

| Workstream | TechFind direction | Later module / dependencies |
|---|---|---|
| On-page SEO | Map distinct user intent to home, category, product, and guide templates; write accurate titles/headings/product copy; complete specs and service facts; strengthen internal links and breadcrumbs; avoid repetitive boilerplate | Module 03 maps terms; Module 04 audits and drafts page improvements; catalog and brand facts required |
| Technical SEO | Confirm crawl/index controls, canonicals, XML sitemap, robots, status codes, mobile rendering, performance, faceted navigation, pagination, product structured data accuracy, and platform release workflow | Module 05; needs domain, staging, CMS/developer and GSC access |
| Content SEO | Build maintained buying guides/comparisons tied to real product questions and in-stock products; use expert review and update cadence; state evidence and limitations | Modules 03 and 06; requires editorial owner and accurate product knowledge |
| Off-page SEO | Earn relevant mentions through useful resources, supplier/manufacturer relationships where legitimate, and public business information; assess backlink profile before setting outreach | Module 07; no purchased links, link schemes, or fabricated backlink metrics |
| Local SEO (conditional) | If a real staffed store or eligible service-area business exists, create/maintain Business Profile and consistent location/service information; otherwise focus on national ecommerce and delivery coverage | Module 08 optional; requires real eligible business location and policy compliance |
| Monitoring/analytics | Configure verified Search Console/GA4 properties and ecommerce events; QA consent, attribution, data retention; report branded/nonbranded visibility and funnel by template/device | Module 09; account access and privacy/consent review required |

## Operating principles

Follow [Google Search Essentials](https://developers.google.com/search/docs/essentials) and the [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide). Create helpful, people-first content, use accessible crawlable links, avoid manipulative links and keyword stuffing, and do not promise rankings. Treat structured data as a machine-readable description that must match visible page facts; eligibility never guarantees a search feature.

## Sequencing and change control

Business/catalog validation → competitor research → keyword research and mapping → page/template audit → technical crawl → prioritized implementation tickets → QA/release → measurement and reporting. Change one deployable set at a time, record URL/template, owner, date, before/after evidence, and rollback path. Establish baselines before setting outcome claims.
